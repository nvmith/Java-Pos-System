# 🧾 Java POS 시스템 (Swing 기반 GUI)

Java와 Swing을 기반으로 개발한 **데스크탑 포스(POS) 프로그램**입니다.  
상품 등록/수정/삭제, 주문 및 결제 기능을 포함하며,  
MySQL 데이터베이스와 연동되어 실시간 상품 정보를 관리할 수 있습니다.

---

## 📌 프로젝트 개요

- **개발 목적**: Java GUI 및 DB 연동 학습
- **개발 기간**: 약 1주
- **개발 환경**: IntelliJ IDEA / Java 17+ / MySQL
- **UI 구성**: Java Swing 수동 배치 방식

---

## 🛠 주요 기능

### 👨‍💼 관리자 화면
- 상품 등록 / 수정 / 삭제 기능
- 바코드 및 상품명 중복 체크
- 유통기한은 8자리 숫자(YYYYMMDD) 형식만 허용
- 상품 목록은 테이블로 표시되며, 클릭 시 자동 입력 필드 채움

### 🛒 주문 화면
- 총 금액 자동 계산
- 현금 입력 시 거스름돈 계산 및 팝업 출력
- 주문 초기화(취소) 기능 제공

### 🔐 메인 화면
- 주문 화면 또는 관리자 화면 선택 메뉴 제공
- 관리자 진입 시 비밀번호(1234) 입력 필요
- 비밀번호는 `JPasswordField`로 마스킹 처리됨

---

## 📂 디렉토리 구조

```
src/
├── dao/            # DB 접근 객체 (ItemDAO)
├── model/          # 데이터 모델 클래스 (Item)
├── service/        # 비즈니스 로직 처리 (ItemService)
├── ui/             # 사용자 인터페이스 (MainGUI, ItemGUI, OrderGUI)
└── util/           # 유틸 클래스 (DBUtil)
```

---

## ✅ 실행 방법

1. **MySQL에서 DB 생성**

```sql
CREATE DATABASE posdb;
```

2. IntelliJ에서 `MainGUI` 실행  
   → `item_table` 테이블은 코드 실행 시 자동 생성됩니다.

3. 관리자 화면은 비밀번호(1234) 입력 시 진입 가능
